# Pembuat Stiker WhatsApp

Aplikasi Android sederhana untuk membuat stiker WhatsApp dari foto.

Alur:
- Tekan + untuk memilih foto.
- **Langsung Jadi Stiker** untuk membuat stiker dari foto.
- **Edit** untuk menambahkan teks atau menghapus background.
- **Simpan ke WhatsApp** untuk menambahkan hasil ke paket stiker.

Catatan: integrasi sticker pack WhatsApp membutuhkan ContentProvider sesuai format yang didukung WhatsApp.
